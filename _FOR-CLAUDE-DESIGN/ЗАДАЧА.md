## Что вообще не работает (известные блокеры)
- В каждом из этих 12 файлов внутри уже есть кучи inline `<style>` и `<script>` lock-loops которые перезаписывают любой внешний CSS через `setTimeout` и `addEventListener('load')`. Внешним CSS их не победить — мы уже пробовали.
- **Победитель**: либо `<style>` блок в конце `<head>` каждого файла с правилами в `@media (max-width: 820px)` и !important, либо inline `style="..."` атрибут прямо на самом `<h1>`, `<img class="canon-l-hero-bg">`, `.canon-l-hero-inner`, `.canon-l-hero-meta` элементах. Inline атрибут с !important побеждает всё.

## Подход
1. Открой `ancient-china-cultural-studies.html` — посмотри как сделан эталон (`.module-hero` структура, opacity 0.28 на hero-bg, gradient overlay через `::after`, pills `.pill`)

4. Pills (`.canon-l-hero-meta` или `.canon-l-hero-pills`) — grid 2×2 на mobile, белый soft-square 10px

## Constraint иллюстраций
В Hello / Easter / Prepositions персонажи **в центре** ассета. `object-position` не помогает. Попробуй `transform: scale(1.2) translateX(-15%)` на `<img class="canon-l-hero-bg">` чтобы зум сжал центр и подвинул вправо — заголовок слева станет свободным.
