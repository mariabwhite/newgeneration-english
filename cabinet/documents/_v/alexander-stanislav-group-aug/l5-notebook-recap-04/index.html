by planeсамолётом

05

Anchor sentence · тренируем структуру предложения

Мария нарисовала на доске «якорь» — предложение с чёткой грамматической структурой. Разбираем по частям: подлежащее → сказуемое → дополнение → «где / когда».
This week has been tough.
There were many work issues to resolve. There were five meetings.
However, in the evenings I was able to distract myself with personal matters.
Alt version (short): I need to solve many issues at work. — Подлежащее I → сказуемое need to solve → дополнение many issues → где at work.
