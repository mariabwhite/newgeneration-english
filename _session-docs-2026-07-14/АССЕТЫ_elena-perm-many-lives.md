## Что делать с ассетами дальше

1. **Изображения** можно генерировать через:
   - **Midjourney / DALL·E / Flux** (photorealistic, control по палитре)
   - **Nano Banana / Recraft** для стилевых иллюстраций
   - Или подбирать под лицензией CC0 / Unsplash / Wikipedia (для исторических портретов и памятников — Wikipedia — единственный юридически чистый вариант)

2. **Аудио** — сгенерировать через ElevenLabs (British female + British male голоса) или Play.ht. Тексты для всех 5 аудио я напишу когда доработаю секции 5, 7, 10, 20.

3. **Загрузка**: положить файлы в `site-public-clean/lingua-boost-lab/b1/elena-perm-many-lives/assets/{img,audio}/`, продублировать в `site/`, `git commit + push` оба репо с явными маппингами (`site` → `deploy-gh-pages:gh-pages`).

4. **Пока ассетов нет** — в HTML стоят `<div class="image-slot">` плашки с описанием ratio (пунктирная рамка + текст). Как только `.webp` появится — заменять один атрибут `src` и убирать плашку.

## Быстрый чеклист для генерации изображений

Prompt-blueprint для photorealistic (Midjourney / DALL·E):

```
[описание сцены], cold northern palette, deep river blue #1E4B7A and ice silver #8FA5C0
against snow-white #F4F7FB background, subtle mist, cinematic lighting,
photorealistic, high detail, [ratio указан выше], --style raw
```

Замени `[описание сцены]` из таблицы выше. Для исторических (Ермак, Строгановы, Дягилев) — добавь `historical painting style` или `oil painting reference`.
